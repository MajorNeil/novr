## Multiplayer
- Joining a server now shows its progress in VR. The game only showed it on a flat overlay the headset can't display, so a join that failed looked like nothing happened.
- While joining, the multiplayer screen shows each step, and **Cancel** stops the join.
- If a join fails, the screen shows the game's reason (wrong version, wrong password, timeout and so on). The box closes by itself once the map starts loading.

0.4.32 brought eye tracking, the threat ring and the new VR menus; see its release notes.

## Install
Close Nuclear Option, run `NOVR.Installer-Win.exe` (or `NOVR.Installer-Linux`), and click Install. It updates an existing NOVR install in place and keeps your settings.
